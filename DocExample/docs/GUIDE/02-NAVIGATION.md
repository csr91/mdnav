# Navegacion Basica

## Arbol

- `Enter` abre archivo o expande carpeta
- `Tab` y `Shift+Tab` cambian foco
- `,` y `.` hacen scroll del preview

## Layout

Proba `!` `@` `#` `$` `%` para cambiar la proporcion entre navegacion y preview (1 a 5). `:@jsonviewer` abre el visor JSON.
